# Thiệp cưới Retro — folder riêng

Một thiệp mời cưới online độc lập, giữ cảm giác giấy in, màu film và typography cổ điển, với chuyển động nhẹ dành cho điện thoại.

Folder này độc lập với bản Antigravity và bản portfolio cũ. Mở bản dựng sẵn bằng cách mở `dist/index.html`, hoặc chạy `npm ci`, sau đó `npm run dev` để chỉnh sửa trực tiếp. Tạo bản production bằng `npm run build`.

Tên đôi, ngày cưới, địa điểm và RSVP trong giao diện là nội dung mẫu. RSVP hiện lưu trên thiết bị khách để minh họa; trước khi dùng thật, cần nối form với email hoặc dịch vụ lưu dữ liệu. Chỉnh nội dung và thay ảnh cưới trước khi gửi thiệp.

Prompt chi tiết, cấu trúc trang và tiêu chí chuyển động: [PROMPT-THIEP-CUOI-RETRO.md](PROMPT-THIEP-CUOI-RETRO.md).
